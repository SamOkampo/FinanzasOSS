# Fase 9.1 — UX Portafolios

Contrato de UI para presentar agregación patrimonial de forma read-only.

- Solo cuentas de dominio investment o crypto.
- Los totales deben reutilizar las métricas de Finance Core.
- Si faltan valores o conversiones de moneda, la UI debe marcar incompletitud y no inventar conversiones.
- No se implementan conectores de 9.2+ en este bloque.
